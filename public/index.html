AI inference · Rust · WebGPU

Evolve LLM

Run open language models on your own GPU from a web page, including models larger than the GPU’s memory. A Rust engine compiled to WebAssembly computes every token in WebGPU shaders and reads the parts of the model each token needs from storage.

  • No machine-learning framework: its own GGUF loader, 25 weight formats, WGSL kernels and tokenizers.
  • Output checked against Hugging Face transformers on the same weights; browser replies match the native build word for word.
  • Rust
  • WebGPU / WGSL
  • WebAssembly

Infrastructure

This website is a small distributed system.

Two CDNs hold identical copies, and two DNS providers answer for the domain. A monitor on AWS Lambda checks both CDNs over HTTPS every minute, moves traffic if the primary fails, and waits for ten healthy minutes before moving back.

Deploys
Same files to both CDNs, verified by hash
Failover
Three failed checks switch DNS, if the standby is healthy
Recovery
Ten minutes of healthy probes before returning
Certificates
DNS-validated in both zones, installed on both CDNs
