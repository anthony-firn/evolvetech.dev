Earlier experiments

  • DeepSeek Orchestrator ↗Infrastructure scaffold

    Terraform, vLLM and CI scripts for fine-tuning, distilling and serving large DeepSeek models on demand with spot instances and idle shutdown. Not yet run at full scale.

  • Computer User ↗Working tool

    Gives an AI assistant a real browser, and hands control back to a person when a site asks them to sign in, then continues with the saved session.

  • RLWE-HDL-Secure ↗Partial hardware design

    Verilog building blocks for ring-learning-with-errors encryption, a basis for quantum-resistant cryptography: modular arithmetic and a number-theoretic transform.

  • Smart Sparsity ↗Early sketch

    A starting point for running large language models with less memory by loading model parts only when needed.

Build with a reason.

Start with a real problem. Keep the system understandable. Share enough of the process for other people to question it and make it better.
