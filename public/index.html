Evolve Inbox

A small inbox for your own domain, built for EvolveTech. Inbound webhooks bring mail into a password-protected reader, with formatted messages, attachments and sender checks.

  • Forward Email handles SMTP delivery; a Netlify Function stores messages in Blobs and serves the reader.

Research tools · Python · Pyodide

Symmetry Forge

A toolkit for the symmetries of graphs and combinatorial designs. The lab runs the unmodified Python package in your browser through WebAssembly — no server involved.

  • Partition refinement and exhaustive search compute automorphism groups and canonical labels.
  • Python runs in a Web Worker with a time limit, so the page never freezes.
  • Correct on the classics: Petersen 120, cube 48, Heawood 336, tesseract 384.

  • Pyodide

This website is a small distributed system.

Two independent CDNs hold separate copies. A monitor probes both over real HTTPS every few minutes and moves DNS if the primary fails, then waits for ten healthy minutes before moving back.
