A TRANSPARENT RESEARCH WORKFLOW

Search broadly. Read carefully.

  1. Define a question. Use several queries with alternate wording. Search for exceptions and adverse authorities.
  2. Import actual sources. Add UTF-8 text or JSON records from a reliable source. Mark summaries and discovery snippets honestly.
  3. Inspect context. Open each result's source and review the complete opinion, procedural posture, court, publication, and later treatment.
  4. Record exact passages. Quotes are checked against the imported text. A pinpoint is required, and every note keeps its own source snapshot.
  5. Export your work. Download the corpus and notebook before closing the tab. Nothing is saved automatically or sent to a server.

What the tool verifies

It checks source-text matches, exact quotation inclusion, required pinpoint fields, and known passage-label mismatches. SHA-256 hashes identify imported text. These checks do not authenticate a source or establish that a case is binding or still good law.

Browser workspace and Python CLI

This browser workspace offers local ranked search, multi-query fusion, phrase concordance, prepared external searches, and evidence export. The downloadable MIT-licensed Python CLI additionally includes SQLite FTS5, authenticated CourtListener discovery, citation graphs, version comparisons, research leads, and authority audits. CourtListener automation requires your own API access; it is not running in this browser.

Privacy and portability

Your imported text, questions, and notes stay in memory in this tab. Export files to keep them. Following an external research link sends that link's query to the selected provider. Source links open the URL you imported. Do not treat the fictional demo as legal authority.
