Pulse Pop

Tap the shrinking pulses before they vanish. Chain hits into combos, earn coins and unlock skins in a 30-second round — one codebase for iPhone, Android and the web.

Play in the browser →Source on GitHub ↗

What I built

  • Game rules — scoring, combo caps, coin payouts and safe cosmetic unlocks — kept separate from rendering and covered by unit tests.
  • One React Native codebase that runs in Expo Go on phones and exports to the static web build on this site.
  • Haptics and local persistence on device, with no accounts, ads, analytics or network services.

What's next

It has not been submitted to the app stores. The repository documents a fair free-to-play model — optional rewarded ads and cosmetic purchases with no paid scoring advantage — but none of it is implemented.
