Developer quickstart

Embed Evolve LLM

Stream local model output into your own interface through a dedicated worker. The example includes a scripted fixture that needs no GPU or model download.

Download browser runtime 0.4.0 →Source on GitHub ↗

Run the example

unzip evolve-llm-browser-0.4.0.zip -d evolve-llm
python3 -m http.server 8080 --directory evolve-llm
# Open http://localhost:8080/examples/

Open the embedding example → Run its protocol fixture immediately, or explicitly download about 145 MB of SmolLM2 weights from Hugging Face for real GPU inference. Fixture text and timing are scripted; they are not an inference result or benchmark.

The bundle contains the SDK, TypeScript declarations, worker, WASM engine, licenses and example. Serve them on the same origin as your app. Inference stays on the device. Internet tools default to off; explicitly enable internet: { enabled: true } per generation to send research queries and public URLs to external providers.

Terminal and Pi

Open Evolve LLM → Select Terminal. The WASM shell works without loading a model. Try printf "pear\napple\n" | sort > fruit.txt && cat fruit.txt. Load a tool-capable Qwen model, then enter pi Read README.txt and write a summary to summary.txt.

Real Pi agent core reuses the loaded local model and exposes sequential file, shell and research tools. The terminal shows actual tool calls and results. Small models can ignore task details; inspect the files and results. This is a browser integration with Pi core, not the complete native Pi CLI.

Files stay in a browser-only /workspace, persist in IndexedDB, and support text import and JSON export/restore. Limits: 4 MiB, 128 files, 32 commands per invocation, 20 seconds per workspace operation; Pi tasks allow 10 model turns, 12 tool calls and 3 minutes. Pipes, quoted arguments and redirects work. Full Bash, host processes, Python, npm and host file access are unavailable.

Enable Web access for search and curl URL. Wikipedia and DuckDuckGo supply search results; Jina Reader reads pages, and an optional Jina key enables its search. Queries and URLs go to those providers. Reads omit cookies and block private URLs; provider limits and CORS apply. No inference server is needed. Unzip the download and open its root on localhost or HTTPS to self-host.

Run apps and games

In Terminal, enter demo snake to play the labeled bundled example, preview snake.html to run your own saved HTML, or test snake.html for a runtime smoke check. No model is needed to run existing files.

Pi can call preview and browser_test, see errors, edit files and test again. Its last successfully written HTML file opens automatically. Pi tokens defaults to 2,048 and can be raised to 4,096; the model context must also fit the task. Invalid or truncated calls report failure and execute no tools from that reply.

The playable preview has Reload, Test, Full size and Stop controls. It runs inline HTML/CSS/JavaScript in an opaque-origin sandbox with no network, storage or parent access. Smoke checks collect runtime errors, inspect canvases, send arrow keys and click Restart; they do not establish complete game correctness. External dependencies and host programs are unsupported.

Try pi Make snake-example.html use a blue background, then browser_test it and preview it. Choose a coding model and review the results.

Stream tokens

Add <pre id="answer"></pre> to your page, then import the runtime from its directory.

import { createEngine } from './evolve-llm/sdk.mjs';

const engine = createEngine();
const answer = document.querySelector('#answer');
try {
  await engine.initialize();
  await engine.load('smollm2-135m');
  for await (const event of engine.generate([
    { role: 'user', content: 'Explain WebGPU in one sentence.' }
  ], { maxTokens: 64 })) {
    if (event.type === 'token') {
      answer.textContent += event.text;
    }
  }
} finally {
  engine.dispose();
}

Control the lifecycle

initialize checks the GPU adapter; load accepts a catalog ID or local File objects. generate returns prefill, token and done events. reset clears chat state, and dispose releases the worker permanently. Each client allows one operation at a time.

Pass an AbortSignal to load or generate. Cancellation, a timeout, a worker failure, or breaking an unfinished stream unloads the model. Reload before the next generation. The default deadline is 120 seconds and can be extended explicitly. Stream buffering is bounded to 1,024 events; a slow consumer receives backpressure. Concurrent operations receive busy. There are no automatic generation retries.
