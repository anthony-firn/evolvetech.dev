Pick a graph or draw your own. Symmetry Forge searches every way to relabel the nodes that keeps the same connections, then colors nodes that the symmetries can swap.

Click one node, then another, to add or remove the edge between them.

    Example symmetries

      Each symmetry is written as cycles: (0 1 2) sends node 0 to 1, 1 to 2 and 2 back to 0. Nodes not listed stay put.

      What runs here

      The real Symmetry Forge Python package, unmodified, running on Pyodide in a background thread. Nothing is sent to a server. The search is exhaustive, so it is limited to 14 nodes; very symmetric graphs near that size are stopped after a few seconds.
